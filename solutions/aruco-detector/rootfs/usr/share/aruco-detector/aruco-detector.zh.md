# 机械臂 ArUco 标定定位码高性能识别系统 (SG2002 RISC-V)

面向 Seeed reCamera（算能 SG2002 单核 1.0 GHz RISC-V 平台）专为机械臂视觉伺服、手眼标定和工件精准抓取开发的高性能标记检测与 6-DoF 位姿解算系统。

## 核心特性
- **零拷贝硬件灰度链路**：直接复用 VPSS 图像处理管道输出的 NV21 Y 分量，完全消除 CPU 端的格式转换与像素搬运开销。
- **纯 C 极简 AprilTag 3 引擎**：轻量级 C99 架构，无大型第三方外部依赖，原生内置常用 ArUco 字典族（`tagAruco4x4_50`, `tagAruco4x4_100`, `tagAruco4x4_250`, `tagAruco5x5_50`, `tagAruco6x6_250`）以及 AprilTag 字典（`tag36h11`）。
- **高帧率与低时延**：单核 1.0 GHz RISC-V 核心全图检测帧率稳定在 25~30 FPS，满足机械臂闭环控制的时延要求。
- **6-DoF 空间位姿解算**：结合相机内参矩阵与标定板真实物理边长，直接解算相机坐标系下的三维平移向量 $tvec = [x, y, z]$（米）及旋转姿态角（Roll, Pitch, Yaw），直接对接 ROS / ROS 2 机械臂驱动节点。
- **MQTT 与 Web 预览**：结构化 JSON 数据经 MQTT 秒级广播；同时通过 8001 端口推流 H.264 调试视频与高亮角点叠加。
